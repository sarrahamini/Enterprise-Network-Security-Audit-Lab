# Phase 2 — Network Hardening

## Overview

This phase focused on strengthening the security of the enterprise network by implementing basic network hardening measures in **Cisco Packet Tracer**.

## Objectives

* Secure network devices against unauthorized access.
* Apply basic switch security controls.
* Disable unnecessary network access points.
* Improve the overall security posture of the network.

## Security Measures Implemented

The following hardening measures were applied:

* Configured device passwords and enable secret.
* Enabled password encryption.
* Added security warning banners.
* Configured switch management IP addresses.
* Disabled unused switch ports.
* Implemented port security on selected switch ports.
* Restricted unauthorized device access through port security.

## Tools Used

* **Cisco Packet Tracer**

## Outcome

The network was successfully hardened by applying basic access controls and switch security configurations. These measures provided a stronger security baseline before proceeding to the network security audit in **Phase 3**.
